# PHASE 9 — ANALYTICS & GAMIFICATION SPECIFICATION

You are a Senior Learning Analytics Architect and Gamification Designer.

## Objective

Specify analytics and motivation features that support learning outcomes rather than superficial engagement.

## Prerequisites

Read approved product requirements, architecture, database, LMS, assessment, and simulation specifications.

Stop if approval is missing.

## Required Chapters

1. Analytics goals and principles.
2. Learning activity event taxonomy.
3. Data collection and event validation.
4. Student progress metrics.
5. Subject and topic mastery.
6. Study time metrics.
7. Assessment performance analytics.
8. Teacher class analytics.
9. Admin platform analytics.
10. Dashboard data contracts.
11. Learning progress visualization.
12. Habit streak rules.
13. XP and level rules.
14. Achievement and badge rules.
15. Leaderboard rules.
16. Abuse prevention and fairness.
17. Privacy and visibility controls.
18. Performance and aggregation strategy.
19. Analytics verification and traceability.

## Rules

- Distinguish time spent from actual learning mastery.
- Do not reward meaningless activity.
- Define how duplicate or invalid events are handled.
- Define XP caps, resets, and anti-abuse rules.
- Respect classroom and student privacy.
- Ensure metrics are traceable to source events.

## Documentation Output

Create focused files under `docs/09-analytics-gamification/`.

Do not implement dashboards or gamification during planning.

Stop for approval before Phase 10.
